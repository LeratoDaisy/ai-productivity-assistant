SYNQ AI — AI Productivity Assistant
Project documentation
A functional front-end prototype exploring how common productivity workflows can be brought together in one interface.

1. Problem statement
People often manage tasks, meeting notes, written communication, and research across separate tools. Switching between these activities can interrupt focus, make priorities harder to see, and increase the chance of missing follow-up actions. SYNQ AI explores how one productivity interface could make these everyday workflows easier to access and organise.
2. Solution overview
SYNQ AI is a web-based productivity assistant prototype built around a central dashboard. It groups workflows for drafting communications, working with meeting notes, organising tasks, exploring a research topic, and asking productivity-focused questions.
Current scope: the prototype demonstrates the interface and interaction flows using sample data and front-end demonstration logic. It is not currently connected to a live AI model, personal email account, or calendar service. Outputs should be presented as prototype demonstrations, not as evidence of live AI processing.
3. Features
- Overview — central view of productivity information and tasks.
- Smart Compose — interface for drafting emails or other communications.
- Meeting Intelligence — workflow for meeting notes, summaries, and follow-up actions.
- Priority Pilot — task creation and completion/prioritisation interactions.
- Insight Lab — workflow for exploring a topic and presenting concise information.
- SYNQ Copilot — conversational-style interface for productivity questions.
4. Tools and technologies
- React — interface components and state-driven interactions.
- Vite — local development server and build tooling.
- CSS — layout, styling, and responsive presentation.
- lucide-react — interface icons.
- Git and GitHub — source control and repository hosting.
The current prototype uses front-end demonstration logic rather than a production AI API.
5. Sample prompts
1. Smart Compose: “Write a polite follow-up email asking for an update on the project timeline.”
2. Meeting Intelligence: “Summarise these meeting notes and list the decisions and action items.”
3. Priority Pilot: “Add ‘Prepare presentation’ as a high-priority task due Friday.”
4. Insight Lab: “Give me a concise overview of how AI can support everyday productivity.”
5. SYNQ Copilot: “Help me plan the three most important tasks for today.”
These examples illustrate intended workflows. Actual results depend on the prototype’s implementation and are not necessarily generated by a live AI model.
6. Challenges and solutions
Challenge: bringing different workflows together. Email drafting, task management, meeting notes, and research have different purposes. SYNQ AI uses a shared dashboard, consistent navigation, and reusable interface components to make the workflows feel like parts of one product.
Challenge: demonstrating functionality before live AI integrations are available. Sample data and front-end interactions make the intended experience demonstrable. The current limitations are stated explicitly so users understand what is and is not automated.
7. Potential impact
SYNQ AI aims to reduce friction between common work activities. Potential benefits include clearer task visibility, more organised meeting follow-ups, a faster starting point for routine writing, and a single interface for exploring productivity assistance. These benefits are goals rather than measured outcomes; user testing would be needed to establish whether the prototype saves time or improves results.
8. Future improvements
- Integrate a live AI model through a secure backend and protect API credentials.
- Evaluate outputs for usefulness, accuracy, and consistency.
- Add optional email or calendar integrations only with explicit user permission.
- Include privacy safeguards and clear user controls.
- Test with users and measure usability and time saved.
Conclusion
SYNQ AI is a functional productivity-interface prototype demonstrating a unified approach to everyday work. It establishes the interface and workflow concept; future development can validate the experience and add secure AI capabilities where appropriate.
